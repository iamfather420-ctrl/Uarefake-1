# 90-second judge script

Open the cockpit. Leave the unsafe request in the box.

**0:00** “An agent that can change records is not an agent that may change records. Watch the difference.”

**0:08** Press **Compile and prove**. “This is not another model writing a proof. A compiler turned the sentence into a typed action. Each row is an obligation. SAT means a countermodel. Production, wildcard targets, no inverse, no human token.”

**0:28** Press **Sign authorization**. “The safe rewrite is computed, not narrated: one demo account, sandbox, checkpoint, inverse. The token is bound to the hash of that action. A stolen token from another action will not match.”

**0:48** Press **Execute bounded op**, then **Reverse state**. “Mutation happens only after UNSAT. Rollback is part of success, not a footnote.”

**1:05** Press **Tamper one field**, then **Re-verify offline**. “The receipt fails. You do not have to trust this interface. The check is the canonical bytes.”

If they ask about latency: point at the worst-of-200 figure. The budget is 25ms because the prove path does not call a model.

If they ask about LangChain or any other agent stack: show the drop-in gate. `proceed` is false until the same obligations hold. There is no side door.

Close: “Capability is not authority. The refusal is the product.”
