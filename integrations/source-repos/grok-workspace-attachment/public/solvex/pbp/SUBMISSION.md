**Title:** UAREFAKE — Proof Before Power

**One line:** An evidence gate that lets an AI propose, proves the action in a finite policy theory, and refuses power when a countermodel exists.

## Description

Most agent demos stop when the model sounds sure. UAREFAKE stops when the action is still only a proposal.

A deterministic compiler turns the request into a typed action. Theory PBP-1 then checks eight obligations: allowlist, tenant, environment, blast radius, reversibility, human authorization, hash binding, and JIT freshness. A failure is a SAT countermodel. Success means the unsafe state is UNSAT in this theory. Only then can a sandbox operation run, and only with a checkpoint and an inverse. The loop ends in a receipt that re-verifies from canonical bytes. Tamper one field and it fails closed.

The prove path does not call a language model. The model may propose. It does not grade its own homework.

## What to click

1. Compile the unsafe production bulk update. Read the countermodels.
2. Sign authorization. See the rewrite bind to a hash.
3. Execute, reverse, export the receipt.
4. Tamper one field and re-verify offline.

## Honest limit

PBP-1 is verified for this action theory. Live production telemetry and payments are not claimed. Those paths stay blocked.
